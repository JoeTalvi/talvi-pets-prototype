# Amendment WORK-037-2 — systems/mec-001-scenes.md, avatar outfit state

Dated 2026-11-03, as-built at the WORK-037-2 lane head (base bbc5c45).

- The avatar wears one whole outfit at a time (DEC-002: whole sets, no mix-and-match): `state.avatar.outfitId`, default `"default"` (the base `player/avatar-sheet`).
- Unlocked outfits are derived by `unlockedOutfitIds` (Pet House complete → `cosy`; the garden's `arrivalDone` → `garden`). Nothing is stored.
- `chooseOutfit { outfitId }` changes the worn outfit when it is unlocked and nothing is open (dialogue, celebration, arrival, site arrival); design mode does not block it (FORK, core amendment). Emits `outfit.changed { from, to }`.
- The outfit survives door transitions (the avatar rebuild on `scene.changed` carries it).
- Not built here (WORK-037-3): the Closet button and picker, the per-outfit sheet swap on `AvatarSprite`, the makeover moment, the reward tile/card.
