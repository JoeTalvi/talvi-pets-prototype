## §2.2 decide / §2.5 reactions: the stripped-charm reaction (DEC-043, OQ-26)

- "The next time the pet looks for a charm" = its next `decide` (the idle timeout of the resident pet in its home room; order fork 1 default).
- At `decide`, when `pets[p].strippedPending` is non-empty **and no dialogue is open**, the pet takes the first entry (FIFO) instead of choosing a target: one pet draw `petPick(lines.stripped)`; the entry is removed from `strippedPending`; behaviour → `reacting`, `reaction: 'stripped'`, `target: null`, `verb: null`, `timerMs = tuning.bubbleTextMs`; events `pet.reacted { petId, reaction: 'stripped', slotId: null, typeId, line, walkOver: false }` then `pet.phaseChanged`. At the timeout the pet returns to idle with a fresh `idleMs` roll (the existing `afterBubble` row: no target, so idle).
- While a dialogue is open the stripped reaction waits (decide proceeds as before and the entry stays queued) — the same hold the want bubbles use.
- One reaction per queued type; a type placed back before its reaction plays leaves the queue (WORK-033-1) and produces none. Hearts, `fulfilledWantIds`, `heartCharms` and verbs never change.
- Deterministic for a seed: the only draw is on the pet stream (invariant 8).
- The immediate `interrupted` 🤔 when the used slot is emptied is unchanged and independent.
- View: `PetSprite` plays `idle` for `stripped` (as for `dislike` / `interrupted`).
